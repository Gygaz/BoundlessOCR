BoundlessOCR

BoundlessOCR is a document processing pipeline designed to transcribe complex PDF files into clean, structured plain text. It is built for multilingual and multi-writing-system documents that often break traditional OCR workflows. By combining PDF splitting, image upscaling, intelligent resizing, and advanced OCR models such as ChandraOCR, BoundlessOCR aims to maximize transcription accuracy across diverse scripts and layouts.
